Sticky Call & Zalo buttons for VietFarmy website with Customizer support.

== Description ==

Adds floating sticky buttons (Call & Zalo) to your WordPress site.
Features:
- Customizer settings for phone number, colors, position
- Pulse animation option
- Mobile responsive
- Easy to configure via Appearance > Customize

== Installation ==

1. Upload `vnf-sticky-buttons` folder to `/wp-content/plugins/`
2. Activate the plugin via Plugins menu
3. Go to Appearance > Customize > Sticky Buttons
4. Configure your phone number and preferences
